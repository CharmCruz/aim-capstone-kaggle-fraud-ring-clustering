# Models

Fitted model files are not stored in this repository — they're generated by running the notebooks and can be regenerated at any time.

## What gets saved here

Running `notebooks/Charmagne Cruz_Capstone Part 2_Step 3 to 5_20260924.ipynb` end-to-end produces two files in this folder:

- `kmeans_k5.joblib` — the final K-Means model (k=5), fit on the full PCA-reduced feature set.
- `dbscan_eps18_26.joblib` — the final DBSCAN model (eps=18.26, min_samples=10).

## Loading a saved model

```python
import joblib

kmeans = joblib.load('models/kmeans_k5.joblib')
dbscan = joblib.load('models/dbscan_eps18_26.joblib')
```

Note: K-Means and DBSCAN were each fit on a sample of the full dataset (20,000 and 10,000 rows respectively — see `README.md` for why), not the entire 590K-row dataset, so predictions on new data should go through the same preprocessing and PCA pipeline used in the notebook before being passed to these models.
